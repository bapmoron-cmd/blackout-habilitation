# BLACKOUT HABILITATION V6

Refonte d'interface autonome. Version V5.3.2 inchangée. Banque et grilles identiques ; transport PDF V5 compatible. Navigation par étapes, un symbole / une situation visible, notes compactes, clavier A/B/C/D, annulation dernière suppression, aperçu PDF non signé, thème sombre/clair. Brouillon local facultatif (IndexedDB, un dossier, non chiffré, aucune signature sauvegardée). Le formateur doit utiliser un poste autorisé. Les exports restent soumis aux validations existantes. Version pilote à vérifier avant usage certificatif.

V6.0.2 : une décision défavorable est clôturée si les éléments nécessaires sont présents, sans être assimilée à une réussite. Les commentaires ne réinitialisent plus l’avis. En cas d’échec pratique constaté dans une situation identifiée, une clôture défavorable peut être enregistrée avant achèvement ; les éléments non observés restent identifiés. Les motifs objectifs sont repris dans le PDF. La liste des tâches et les exports utilisent le même contrôle. Un avis défavorable sans échec objectif nécessite une justification.

V6.0.3 : accès séparé `formateur-test.html` depuis le mode réel. Préremplit un dossier fictif BR et un PDF théorique simulé. Une situation minimum par symbole en démonstration, sans modifier les seuils A/B/C/D ; les grilles réelles restent inchangées. Aucun import de données réelles ni accès aux brouillons réels depuis le mode test. Chaque page des PDF test porte un marquage démonstration et sans valeur administrative.

V6.0.4 : raccourci Test PDF en haut de l’espace formateur. Dans la page de simulation, le bouton « Tester les deux PDF » utilise le pipeline normal de génération avec un visa graphique portant explicitement la mention fictive, puis relit les deux PDF pour vérifier la pagination et le marquage. Aucun dossier réel ne peut bénéficier de ce visa. Les signatures manuelles précédentes sont restaurées à la fin. Les exports restent marqués démonstration ; aucune donnée de test n’est enregistrée dans le brouillon réel. Une modification invalide les fichiers de test générés précédemment.

V6.0.5 : le dossier réel en cours dispose d’un aperçu de contrôle et d’un export complet de contrôle sans minimum de situations, sans théorie ou identité entièrement renseignées, sans signature. Les avis saisis sont explicitement provisoires, les cases et propositions PROMEO neutralisées et chaque page porte un marquage BROUILLON DE CONTROLE. Les données d’origine et les signatures en mémoire restent inchangées. L’export officiel conserve ses validations, y compris les minima des grilles. Le mode fictif séparé est conservé.

V6.0.6 : le formulaire normal permet désormais de clôturer un dossier avec au moins une situation entièrement évaluée, sur adaptation explicite et motivée. Le minimum d’origine reste affiché. L’écart, le nombre effectivement réalisé et la validation éventuelle du référent déclarée par le formateur sont tracés dans le PDF signé. Sans validation du référent déclarée, un avis favorable reste sous réserve et le symbole n’est pas proposé dans le tableau PROMEO. Les seuils A/B/C/D, l’évaluation théorique, le contrôle d’identité et les signatures restent requis. Cette modification n’est pas une validation institutionnelle du changement de minimum. Le brouillon de contrôle reste disponible ; aucun nouveau lien obligatoire.

V6.0.7 : nombre de situations laissé au formateur ; une situation initiale et ajout/suppression libre, situations entièrement vides ignorées à la clôture. Pas de justification ni déclaration de validation supplémentaire pour le nombre de situations. Les minima de référence issus des grilles fournies restent affichés, le nombre intégralement évalué et tout écart sont reportés dans le PDF et dans les indications du tableau PROMEO. Un avis favorable du formateur ne constitue pas la preuve que le minimum de la grille a été respecté. Les situations commencées restent à terminer, sauf clôture défavorable sur un échec observé ; barème et théorie inchangés. Le test apprenti saisit nom, prénom, groupe, entreprise, lieu, organisme et date de théorie ; PDF visible et métadonnées compatibles avec les anciens PDF ; import par liste de champs autorisés, vérification formateur obligatoire. Commentaires types modifiables sur observations, indicateurs et justifications, avec bilans calculés et aucune insertion automatique.
V6.0.7.1 : libellés cohérents dans l’interface et le dossier PDF ; les situations entièrement vides ne sont ni imprimées comme épreuves ni comptabilisées dans le nombre de situations commencées.

V6.1.0 : rapport complet repensé : synthèse d'ouverture, conclusion, avis PROMEO original signé, résultats par symbole, grilles en couleurs, erreurs théoriques et pratiques, réussites A, écarts B/C/D, signatures et annexe originale. Les informations et constats sont issus des notes, du PDF et de la saisie du formateur. Les écarts au minimum de référence restent explicitement signalés. Aucun changement du barème ou de la banque.
